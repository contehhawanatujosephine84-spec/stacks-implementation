# Stack-Based Expression Evaluator

This Project covers the DCOMP320 Data Structures and Algorithm assignment on stack implementation.

## Files

- `stack_evaluator.py` contains the Python source code.
- `input.txt` contains sample mathematical expressions.
- `output.txt` is generated by the program.


## How To Run

Open a terminal in this folder and run:

```bash
python stack_evaluator.py
```

The program reads expressions from `input.txt`, evaluates them using stacks, and writes the results to `output.txt`.

## Input Format

Each mathematical expression should be written on its own line. Separator lines made only of hyphens are preserved in the output.

Example:

```text
3 + 5 * 2
-----
(8 / 4) + 7 * 2
```

## Output Format

The output file keeps the same separator lines and replaces each expression with its evaluated result.

Example:

```text
13
-----
16
```

## Supported Operations

The evaluator supports:

- Addition: `+`
- Subtraction: `-`
- Multiplication: `*`
- Division: `/`
- Parentheses: `(` and `)`
- Operator precedence
- Negative numbers
- Decimal numbers

## Assumptions And Limitations

- Expressions must contain valid mathematical syntax.
- Separator lines must contain only hyphens.
- Division by zero is reported as an error.
- The program uses normal left-to-right evaluation for operators with the same precedence.
